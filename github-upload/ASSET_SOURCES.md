## Maintenance

- When replacing an asset, keep the filename stable when possible, then add a version query in `game.js` or `index.html` to avoid browser cache issues.
- Record exact source URLs for any new externally downloaded assets.
- If an asset has uncertain licensing, keep it for local prototype use only unless replaced by a licensed alternative.
